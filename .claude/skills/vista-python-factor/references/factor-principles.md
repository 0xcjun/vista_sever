# Vista Python 因子设计原则

本文档汇总 Vista 项目 Python 类因子的核心设计原则，统一覆盖时序因子（TSE）和截面因子（CSE）。事件因子的事件判定原则参见 [`operators-events.md`](operators-events.md)。

## 1. 逻辑性优先

因子必须有清晰的金融逻辑，**避免纯数据挖掘的黑盒因子**。

- ✅ 能用一句话解释因子捕捉了什么市场现象（动量、反转、量价齐升、估值偏离…）
- ✅ 能说明因子为什么有效（行为金融、市场结构、套利机制…）
- ✅ 能解释因子正负值的含义
- ❌ 避免随机组合多个指标
- ❌ 避免参数过多 / 过度复杂的非线性叠加

## 2. 量纲一致性

不同量纲的数值不可直接相加/相减；同向量纲才能比较。

```python
# ❌ 错误：价格 + 成交量
df['x'] = df['close'] + df['vol']

# ✅ 正确：使用比率 / 标准化
df['x'] = df['ma5'] / df['ma20']
df['x'] = (df['pe'] - df.groupby('dt')['pe'].transform('mean')) / df.groupby('dt')['pe'].transform('std')
```

## 3. 横向 vs 纵向比较

| 比较维度 | 引擎 | 典型操作 | 适用 |
|---------|------|---------|------|
| **纵向**：单标的不同时间 | TSE | rolling / shift | 趋势、动量、波动率 |
| **横向**：同一时间不同标的 | CSE | groupby('dt').rank/zscore | 排名、相对估值、行业中性化 |

**截面因子的关键约束**：必须在 `groupby(level='dt')` 内做截面操作；任何 `groupby('symbol')` 都退化为时序操作。

## 4. 防未来信息泄露

| 操作 | 错误 | 正确 |
|------|------|------|
| `rank` | `df['close'].rank()`（全样本） | `df['close'].rolling(20).rank()` |
| `shift` | `df['close'].shift(-1)` | `df['close'].shift(1)` |
| `pct_change` | `df['close'].pct_change(-5)` | `df['close'].pct_change(5)` |
| `rolling` | `df['close'].rolling(-5)` | `df['close'].rolling(5)` |

时序因子必须通过 `validate_factor.py --type ts` 静态检查。

## 5. 常见因子类型

### 趋势类（TSE）
均线斜率、MACD、ADX、长短期均线比……
> 思想：价格存在持续性，趋势会延续一段时间。

### 动量类（TSE / CSE）
ROC、RSI、Williams %R、过去 N 日累计收益……
> 思想：历史强势的标的短期内倾向继续强势；也可在截面上比较。

### 反转类（TSE / CSE）
短期超买超卖、布林带反弹、长周期均值回归……
> 思想：极端偏离后倾向回归。

### 波动率类（TSE）
ATR、历史波动率、布林带宽度……
> 思想：波动率包含风险与机会信号；存在低波异象。

### 成交量类（TSE）
OBV、量比、量价配合度……
> 思想：成交量反映资金流和情绪，量价齐升 / 背离都是有效信号。

### 排名 / 标准化类（CSE）
按估值、市值、成长指标做截面排名或 zscore；可加入行业中性化。
> 思想：在每个时间点选出"相对最好"的标的。

### 事件类（EDE）
突破、跳空、放量、极端波动、形态反转、均线金叉死叉……
> 思想：标记一次性事件作为开仓信号。详见 [operators-events.md](operators-events.md)。

## 6. 设计建议

1. **从逻辑出发**：先有假设再造因子，不要先有数据再找逻辑
2. **使用比率/相对量**：避免量纲不一致
3. **多参数组合 > 单一极值**：减少过拟合
4. **样本外验证**：保留近 1-2 年数据做回测
5. **关注稳健性**：在不同市场环境（牛熊震荡）下都有效才算好因子
6. **关注差异化**：与已有因子相关性低才有边际贡献
7. **可解释性优先**：解释不清的因子大概率是噪音

## 7. 因子评估标准

一个好的因子应该满足：

| 维度 | 时序因子 | 截面因子 |
|------|---------|---------|
| **逻辑清晰** | ✅ | ✅ |
| **IC 绝对值** | > 0.03 (一般) / > 0.05 (优秀) | 同左 |
| **单调性** | 分组收益单调递增/递减 | 同左 |
| **稳定性** | 不同市场状态都有效 | 同左 |
| **差异化** | 与已有因子相关性 < 0.6 | 同左 |
| **可计算性** | 计算效率高、易实现 | 同左 |

## 8. 常见陷阱

| 陷阱 | 表现 | 防范 |
|------|------|------|
| **过拟合** | 历史完美、实盘崩盘 | 简单逻辑 + 样本外验证 |
| **未来信息** | 回测完美、实盘亏 | `validate_factor.py --type ts` 强制校验 |
| **量纲不一致** | 因子值范围异常 | 使用比率 / 标准化 |
| **数据挖掘** | 因子无逻辑 | 从金融逻辑出发，可解释性优先 |
| **样本偏差** | 包含新股/退市股 | 过滤上市天数 |
| **存活者偏差** | 只看现存样本 | 使用全历史样本 |
