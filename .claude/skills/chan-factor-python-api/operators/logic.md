# 逻辑与比较算子 (10)

返回布尔结果（1.0 = true，0.0 = false）。NaN 参与比较结果为 0.0。

## 比较算子

| 算子 | 语法 | 说明 |
|------|------|------|
| Gt | `$x > $y` 或 `Gt($x, $y)` | 大于 |
| Ge | `$x >= $y` 或 `Ge($x, $y)` | 大于等于 |
| Lt | `$x < $y` 或 `Lt($x, $y)` | 小于 |
| Le | `$x <= $y` 或 `Le($x, $y)` | 小于等于 |
| Eq | `$x == $y` 或 `Eq($x, $y)` | 等于 |
| Ne | `$x != $y` 或 `Ne($x, $y)` | 不等于 |

支持链式比较：`$a < $b < $c` 等价于 `($a < $b) & ($b < $c)`

## 逻辑算子

| 算子 | 语法 | 说明 |
|------|------|------|
| And | `($x) & ($y)` 或 `And($x, $y)` | 逻辑与 (x≠0) && (y≠0) |
| Or | `($x) \| ($y)` 或 `Or($x, $y)` | 逻辑或 |
| Not | `Not($x)` | 逻辑非 |

## 条件算子

| 算子 | 语法 | 说明 |
|------|------|------|
| If | `If($cond, $then, $else)` | 三元条件选择 |

## 示例

```python
cf.compute_factors(data, [
    "If($close > $open, 1, -1)",              # 阳线/阴线标记
    "If($close > Mean($close, 20), $close, 0)",  # 站上均线才取值
    "($close > $open) & ($vol > Mean($vol, 5))",  # 放量阳线
])
```
